# 叫号条（Callslip）

银行网点柜面叫号：取号入队 → 叫号推进 → 过号回收/重叫 → 当日队列封口。

- 前端 http://127.0.0.1:6400
- API http://127.0.0.1:11400
- `docker compose up -d --build`

## 窗口收档口径：以有在办拒收档为准（全局唯一）

收档与在办争用只贯彻一种架构：**窗口仍钉着当前号指针，则收档整笔失败**。

- **拒收档**：开闭态、当前号指针、在办号牌状态一律不变；在办号继续可办结或过号；
  仅落一条 `拒收档` 审计事件，回执给出拒因与在办号。
- **收档成功**：开闭态与 `收档` 事件在同一写事务落库，半截即整体回滚；
  收档后该窗不得再叫号占办。
- **可重放**：重复收档/开档幂等，回执指向首次事件（`重复=true`），不重复落事件。
- **联动同刷**：收档回执、窗口页、在办号状态、事件流（`/api/叫号流水`）、
  等候墙、总览（开放窗与办理中桶）同源同事务，收档后不会出现仍占办。
- **并发**：所有写接口 `BEGIN IMMEDIATE` 串行化，收档与叫号只分先后、不留半截。

接口：`POST /api/窗口/{id}/收档`、`POST /api/窗口/{id}/开档`，
无论成败均返回收档回执（结果/拒因/在办号牌/事件编号/时刻）。

种类停用与日切为独立需求，不在本口径内。
